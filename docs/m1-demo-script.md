# TraceDelta M1 可复现演示脚本

> 本文档严格对应 **M1 已实现能力**。M2–M5（并发评测调度与恢复、Trace/Span、五维回归分析、质量门禁、性能压测与真实模型实验指标）均处于**规划中**，不在本脚本演示范围内。

## 1. 本地启动

1. 启动依赖（MySQL 8 + Redis 7）：
   ```bash
   docker compose up -d
   ```
2. 确认根目录已配置 `.env`（包含本地数据库凭据、`TRACEDELTA_MASTER_KEY` 与管理员初始密码；严禁提交 `.env`）。
3. 启动 Spring Boot 后端（JDK 21，监听 `http://localhost:8080`）：
   ```bash
   set -a && source .env && set +a
   mvn -f backend/pom.xml spring-boot:run
   ```
4. 启动 Vue 3 前端控制台（监听 `http://127.0.0.1:5173`，代理 `/api` 至 `:8080`）：
   ```bash
   npm --prefix frontend run dev -- --host 127.0.0.1 --port 5173
   ```

## 2. 演示闭环步骤

### Step 1：登录与主题切换
- 打开 `http://127.0.0.1:5173/login`，验证标题与定位文案「数据集版本与模型渠道验证工作台」。
- 使用右上角 `浅色 / 自动 / 深色` 单选组切换三态主题（支持键盘左右方向键），刷新页面确认首屏无闪烁。
- 先故意输入错误密码提交，验证错误提示不泄露账户存在性且焦点自动回到密码输入框；再输入本地管理员账号密码登录进入 `/datasets`。

### Step 2：创建数据集与导入不可变版本 v1 / v2
1. 在 `/datasets` 点击「新建数据集」，创建例如 `java-rag-qa-demo`（说明：`Java 后端 RAG 基础回归题库`）。
2. 在紧凑表格中点击进入版本详情页 `/datasets/:id`。
3. 点击「导入新版本」：
   - 先粘贴一段非法 JSONL 或重复 `case_key`（如 `case-01` 与 `CASE-01`），观察物理行号高亮、错误摘要与点击跳转定位，以及禁用提交。
   - 点击「填入 JSONL 示例」，查看本地预检通过摘要（预计 `v1`、2 条用例），提交后以服务端真实响应创建 `v1`。
4. 再次点击「导入新版本」，切换格式为 `JSON` 或修改其中一条用例的 `reference_answer` 并新增 `case-03`，填写备注（例如 `新增边界用例并更新参考答案`），提交生成 `v2`。
5. 验证不可变快照与哈希可追溯性：
   - 在左侧版本历史在 `v1` 与 `v2` 之间切换，确认选中态（左指示条 + `当前` 徽标）与顶部「只读快照」标识清晰可读，且历史版本不可被编辑。
   - 点击 `v2` 顶部「对比 v1（本地）」，查看基于 `case_key` 与 `case_hash` 本地计算的新增 / 修改 / 删除摘要。
   - 点击任意用例的 `case_key` 或「查看」按钮打开只读检查器，查看并一键复制完整 64 位 SHA-256 `case_hash`。

### Step 3：确定性 Mock 渠道与单次冒烟测试
1. 切换到 `/providers`，确认页面载入后不出现无来源的绿色健康点，未测渠道均明确标注「本次会话未测试」。
2. 点击「新增渠道」，保持类型为 `Mock（本地确定性）`，分别选择或演示不同档位：
   - `mock-good`：稳定返回合法内容与标准 Token 统计。
   - `mock-flaky`：按 `seed` 与 `failRate` 确定性模拟间歇失败（展开「高级配置」可查看/校验 JSON 参数）。
3. 点击刚创建的 `mock-good` 渠道的「冒烟测试」，在抽屉中点击「执行单次冒烟测试」：
   - 核查真实返回的单次耗时（`latencyMs`）、Token 计数、估算费用与响应内容。
   - 关闭抽屉，确认列表该行更新为「本次成功 · Nms」与测试时间；刷新页面后重置为「本次会话未测试」（因 M1 未持久化冒烟历史）。

### Step 4：OpenAI 兼容渠道的加密存储与掩码展示
1. 点击「新增渠道」，切换类型为 `OpenAI 兼容`，观察表单切换为「默认模型 / Base URL / API Key」，不再混入 Mock 配置。
2. 填入任意兼容端点（例如 `https://api.deepseek.com/v1`）、模型名与测试密钥保存。
3. 验证安全边界：
   - 列表中 API Key 仅展示后端返回的只读掩码（如 `sk-****xxxx`），不提供“复制完整密钥”误导操作。
   - 点击 `··· → 编辑配置`，确认输入框不回填明文或掩码，明确提示“留空将保留原加密密钥”。
   - **费用与调用边界说明**：Mock 渠道完全本地运行、零费用且确定性可复现；OpenAI 兼容渠道的冒烟测试会发送真实外部 HTTP 请求（30s 超时）并可能产生上游费用，且外部 LLM 调用遵循 At-Least-Once 语义，不承诺 Exactly-Once。
